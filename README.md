# Meus APPs — downloads

APK experimental para teste em Android ARM64. Não é uma versão de produção. O login e a instalação em TV ainda precisam ser testados. Os aplicativos que exigem dados adicionais e os sistemas diferentes de Tizen ainda não estão disponíveis.

O código do projeto é mantido separadamente em repositório privado. O APK utiliza componentes do projeto Apps2Samsung, distribuídos sob licença MIT, com avisos incluídos no projeto de origem.
